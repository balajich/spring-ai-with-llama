🧠 Spring AI with Llama #6 — Chat Memory: Fixing Goldfish Memory

Ask your AI bot a follow-up question and it has no idea what you were just talking about - every call is stateless. We fix that with MessageWindowChatMemory and MessageChatMemoryAdvisor.

Suddenly onboarding works like a real conversation, each employee gets an isolated session, and the memory window keeps the token budget bounded.
