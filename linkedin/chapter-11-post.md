🔌 **Your REST API is already built. Now let every AI agent use it.**

Chapter 11 of "Spring AI with Llama" covers MCP (Model Context Protocol) — a standard for exposing an existing REST API as tools any AI agent can discover and call at runtime.

We wrap TechCorp's calendar service once, and suddenly the SmartHR chatbot, a Slack bot, and a careers portal can all book interviews through the same API — without duplicating a line of logic. The key insight: MCP separates *who implements the tool* from *who calls it*, connected asynchronously over SSE.

One integration, every agent.
